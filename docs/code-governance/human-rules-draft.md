# 人工规则草案（供团队人类成员审阅）

> 状态：**DRAFT（AI 起草的草案）**。**不是**已批准政策。
> 用途：供团队人类成员审阅后，**人工转移**到 `.opencode/rules.md` 并批准。
> 本文件由 `docs/code-governance/` 维护；代理可编辑草案，但**不得**把草案内容冒充为已批准规则。

## 1. 适用范围

本规则适用于所有在 `cs5351-tradingagents` 仓库工作的编码代理与团队成员。

## 2. 核心原则（草案）

1. **诚实**：不伪造批准、身份、结果、完成度、评审、bug、transcript。
2. **先批准后实现**：测试计划与实现计划须人工批准；安全变更须 ADR。
3. **默认拒绝**：不确定、缺失、超限一律 fail-closed 或 abstain。
4. **最小权限**：按角色路径白名单；冻结路径不得写。
5. **可验证**：所有断言可追踪到证据或标注为假设。

## 3. 代理约束（草案）

- 业务编码只能由受 `AGENTS.md` 约束的编码代理完成。
- 禁止绕过代理手工修补业务代码。
- 禁止读取 `.env*`、auth、git 元数据、外部目录、隐藏 home 文件。
- 禁止在线 API 调用、提交、推送（除非人工明确授权）。
- 提示词/模型变更先固定评估集并先评测。

## 4. 人类专属（草案）

- `.opencode/rules.md`：由人类撰写与批准。
- `docs/approvals/**`：只允许人类写入真实批准记录。
- 课程 gate 基础设施：由人类定义。

## 5. 变更（草案）

- 本草案的变更需人工评审。
- 转移到 `.opencode/rules.md` 后，代理不得再编辑。

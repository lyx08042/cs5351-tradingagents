# 运行时提示词（Prompts）

> 状态：**PROPOSED 候选，未激活**。本目录中的提示词**不会**自动接入上游基线；上游基线提示词保持不变（见 `tradingagents/agents/**`）。
> 提示词/模型变更必须先固定评估集（`docs/evaluation/cases.yaml`）并先评测，再经人工批准。

## 2. 激活流程（planned）

1. 固定评估集并记录基线。
2. 在本地以真实凭证运行评估（凭证不入库）。
3. 结果写入 `docs/architecture/evaluation-logbook.md`（含失败）。
4. 提交实现计划 + 评估证据，取得人工批准。
5. 仅在批准后接入（协调 PR），并更新 `docs/ai-use-log.yaml`。

## 3. 与上游的区别

- 上游提示词是**基线**，不在本目录。
- 本目录仅为**候选**，修改它们不影响运行时行为，除非显式接入。
- 不得宣称候选提示词已改善指标——尚无评估。

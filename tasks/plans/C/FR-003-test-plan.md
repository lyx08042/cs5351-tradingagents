## 1. 测试输入与验收

离线夹具使用固定标的、日期、账户快照和规则版本。示例夹具使用 USD、可用现金 1,000、同一标的持仓 5、价格 100；数字只用于测试。按单一故障构造负例，判定须同时检查 verdict 和原因码。最终字段名与 C 接口一致。

| 用例 | 输入或场景 | 预期 | 需求 |
| --- | --- | --- | --- |
| T01 | Buy 2；另测 Sell 2 | 两个独立用例均通过，覆盖买卖正例 | FR-003 |
| T02 | 合法 Hold，数量 0，显式账户快照和规则版本齐全 | 通过并标记为无操作，可执行交易提案数为 0 | FR-003、INV-003 |
| T03 | Buy 11，现金 1,000，单价 100 | 拒绝，原因为现金不足 | FR-003、INV-003 |
| T04 | Sell 6，可信持仓 5；另测数量为 0 或负数的 Buy/Sell、负持仓 | 分别拒绝并报告持仓不足或数值违规 | FR-003、INV-003 |
| T05 | 缺快照、缺规则版本、没有显式空仓的空持仓、缺必要现金；另测有足够现金且显式空仓的合法 Buy | 各缺失情形分别拒绝。显式空仓正例通过，证明能够区分未知与空仓 | FR-003、INV-003 |
| T06 | 价格为 0、负数、NaN、无穷或币种不一致 | 拒绝并报告相应原因。等号、费用及精度用例按确认后的计价口径补充 | FR-003、INV-003 |
| T07 | 以正常程序入口运行固定的现金不足提案，模型自报已批准或自报更高现金 | C 拒绝，已验证模拟交易提案发布次数为 0。捕获明确原因。另用合法 Buy 验证同一入口确实能发布，以排除假通过 | FR-003、INV-003 |
| T08 | 通过另一个正常入口运行同一提案；分别模拟缺少结构化候选和校验异常 | CLI 与程序入口的关卡行为一致。缺候选和异常均无已验证交易提案 | INV-003 |
| T09 | 输入真实券商或下单意图；核对代码、依赖和可达调用 | 拒绝，真实执行路径为 0 | SEC-001 |
| T10 | 固定同一提案、可信快照和规则版本，重复两次并与 E 的回放结果比较 | 决定与原因码一致，校验对模型和外部 API 的调用次数为 0。E 尚未接入时只记录 C 本地的确定性证据 | NFR-003 |

T07、T08 使用真实的入口到安全判定再到输出的路径。只替换模型及外部数据源，保留真实 C 校验器。基线中的报告或决策记忆仍可生成，集成断言观测的是**已验证模拟交易提案**。若将来存在可写的模拟账户，再增加拒绝路径对订单、现金和持仓写入次数为 0 的断言。

## 2. 基线、命令与 CI

- 先用既有 `tests/test_graph_end_to_end.py`、`tests/test_portfolio_context.py` 和 `tests/test_structured_agents.py` 的相关用例确认原版的图运行、账户输入和结构化或文本回退行为。已有测试属于冻结基线。 [上游回归目录](https://github.com/lyx08042/cs5351-tradingagents/tree/7dc46516935755d5a09ba3507ccd55dbadda066b/tests)
- 对照时固定股票、日期、账户与上游输出，分别记录旧版可观测的评级或报告和改进版的关卡结果。原版没有等价的 C 关卡时，记录「原版无该观测点」，保留旧版实际输出，不将分析建议记成已执行交易。
- 按仓库说明配置开发及课程测试依赖。以下是后续验证命令；本次只读调查未运行这些命令。 [测试目录说明](https://github.com/lyx08042/cs5351-tradingagents/blob/7dc46516935755d5a09ba3507ccd55dbadda066b/test/README.md)

python scripts/check_course.py --root .
python -m pytest -q

# BUG-004 — reproduction and fix evidence (role B)

> Companion to `docs/bug-diary.md` entry BUG-004. Every number below came from a real command run on
> 2026-11-15; the one figure that was not archived at the time is marked as such.

## Symptom

A budget cap **above** the recorded baseline degraded the run.

```
cap = 240,000 tokens      baseline = 228,275 tokens
observed: the replay applied L1 and reported 177,519 tokens instead of leaving the run untouched
```

## How it surfaced

Not from a unit test — from replaying the recorded baseline trace. Each policy test exercised a single
stage in isolation, so every stage-level rule looked correct on its own; only a full 19-call trace exposed
that the rules fire near the end of any stage.

## Root cause

Two rules compared the remaining budget to a fixed fraction of the total:

- global: `remaining_global < 15% of limit` → L3, `< 10%` → L4
- stage: `remaining_stage < 1.5 x next estimate` → L1

Both are true of almost every healthy run in its final third, so the controller degraded runs that
comfortably fit.

## Fix

Commit `aade521` made level evaluation projection-aware:

```
evaluate(ledger, stage, *, remaining_calls=None, projected_remaining_tokens=None)
```

When the caller can forecast, the global level compares the remaining budget against the projected
remaining spend, and the stage level compares stage budget against the calls still ahead. The fixed
fractions remain only as the fallback for callers without a forecast.

## After the fix

`bug-004-after-fix.txt` (same command family, same cap):

```
limit=240000 calls=19 tokens=228275 level=L0 degradations=0
```

## Regression guard

`test/offline/test_budget_replay.py::test_a_generous_budget_changes_nothing` now fails if a cap above the
baseline ever degrades the run again.

## Honest note

The pre-fix figure (177,519 tokens, L1) was printed to the terminal during the first replay run but was not
saved to a file at that moment. It is recorded here from that run; the post-fix figure is archived in
`bug-004-after-fix.txt` and can be regenerated by anyone with:

```
python -c "from tradingagents.course.budget.replay import baseline_trace, replay; \
print(replay(baseline_trace(), limit_tokens=240000).to_dict())"
```

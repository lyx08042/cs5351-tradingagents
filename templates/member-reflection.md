# 成员反思模板

> 模板。每人一篇，**300–500 WORDS**（英文词数，与 `Report.md` 一致；中文计数需教师澄清，不得以字符替代）。身份待填，不得虚构。

```markdown
## <成员姓名 / 学号>

- 功能模块（固定）：<A–E 之一>
- 流程角色（按 sprint 轮换）：<coordinator/architect/build operator/verifier/reviewer-release>
- 负责需求：<REQ-ID>

### 贡献与可验证证据
- <PR / commit / 测试 / 评审 / 评估记录（真实）>

### 反思（300–500 WORDS）
<真实反思：做对了什么、遇到什么问题、如何改进、对团队协作与验证流程的看法>
```

> 反思必须本人撰写；不得代写或虚构；不得用中文字符数冒充 WORDS。

# Bug 条目模板

> 模板。只记录真实观察；未证实的差异标注 “未证明为 bug”。

```yaml
- id: BUG-000x
  title: <...>
  observed_at: <YYYY-MM-DD>
  environment: <commit/model/config>
  steps: <复现步骤>
  expected: <...>
  actual: <...>
  evidence: <脱敏引用>
  status: <open|confirmed|fixed|wontfix|needs-review>
  owner: <A|B|C|D|E>
  note: <是否证明为 bug>
```

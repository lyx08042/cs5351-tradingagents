## 1. 要求

- 五人各提交**一份完整、带注释的原始会话记录**。
- 命名：`transcripts/<studentid-name>/`（学生身份由本人填写；代理不得虚构）。
- 原始记录**完整、不可变、追加式**；注释放在**单独**文件（见 `templates/transcript-annotations.md`）。
- 不得提交**空的或伪造的**记录；不得包含 API key、auth、个人信息或未公开数据。
